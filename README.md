# PlanParse
This repository holds the code for the advanced ICT project (IKT464)

- Fokusere på utnyttingsgrad, hvilken type utnyttingsgrad gjelder? Ny/utdatert?

- Bjarne finner eksempler på bestemmelser med utnyttingsgrad, gammel beregning av utnyttingsgrad og uten utnyttingsgrad

- Lage en model som kan klassifisere hvilke case som gjelder for en bestemmelse:

  - Riktig beregning av utnyttingsgrad

  - Gammel beregning

  - Uten utnyttingsgrad
  
- Også kunne identifisere disse

  - Utnyttingsgrad kun i kart

  - Utnyttingsgrad kun i dokument

  - Utnyttingsgrad i begge.

Pdf kartet går over bestemmelsene hvis det er avvik. Pdf og bestemmelser har juridisk hold.
